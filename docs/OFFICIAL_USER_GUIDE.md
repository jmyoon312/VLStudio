## 1. 시스템 소개 및 워크플로우 개요

ViraLoop Studio는 트렌드 영상 소싱부터 AI 대량 제작, CapCut 프로젝트 자동 조립, 그리고 다채널 무인 배포 및 계정 육성까지 전 과정을 자동화하는 **올인원 엔터프라이즈 콘텐츠 OS**입니다.

```
┌─────────────────┐     ┌──────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│ 1. 소싱 및 분석 │ ──> │ 2. AI 창작·각색  │ ──> │ 3. CapCut 조립  │ ──> │ 4. 자동 배포·육성│
│ (보관함/대본실) │     │ (Flow AI / 대본) │     │ (No-ZIP 다이렉트)│     │ (쇼츠 배포/웜업)│
└─────────────────┘     └──────────────────┘     └─────────────────┘     └─────────────────┘
```

## 2. 수집 영상 보관함 (`/gallery`)

수집된 글로벌 숏폼 영상을 체계적으로 관리하고, AI 분석 및 CapCut 제작으로 즉시 연결하는 라이브러리 허브입니다.

### 🌟 주요 기능 및 최신 개선 사항
1. **🔗 유튜브 원본 영상 원클릭 바로가기**:
   - 영상 상세 모달 좌측 상단의 **`[🔗 유튜브 원본]`** 빨간색 버튼
   - 그리드 카드 호버 툴바의 **외부 링크(`ExternalLink`)** 아이콘
   - 카드 하단 제목 우측 링크 아이콘을 통해 원본 소스 페이지를 즉시 열어 조회수, 댓글, 반응을 바로 확인할 수 있습니다.
2. **⚡ 직관적인 상태 라벨 (`⚡ AI 제작 가능`)**:
   - 영상 다운로드 및 메타데이터 분석이 완료된 영상에 명확한 `⚡ AI 제작 가능` 뱃지를 부여하여 제작 대기 상태를 한눈에 파악합니다.
3. **📂 스마트 폴더 열기 & 클립보드 복사 (하이브리드 지원)**:
   - **데스크톱 앱 환경**: `[폴더 열기]` 클릭 시 윈도우 탐색기(`explorer.exe`)가 실행되어 해당 영상 파일이 위치한 폴더를 직접 엽니다.
   - **웹 / 모바일 브라우저 환경**: 표준 저장 경로(`07_Downloads/{카테고리}/{채널}/...`)를 **클립보드에 0.1초 만에 자동 복사**하고 안내 토스트를 띄워 원격에서도 파일 경로를 쉽게 활용할 수 있습니다.
4. **🎬 1080p Full HD 무손실 표준 다운로드**:
   - 모든 영상은 최초 수집 시점부터 `1080p Full HD(AV1/H.264)` 최고 화질로 저장되므로, 별도의 재다운로드 과정 없이 최상의 품질로 제작에 활용됩니다.

## 3. 수집 대본 분석실 (`/script-lab`)

수집된 영상의 음성을 Whisper AI로 정밀 추출하고, 3초 후킹 구간/본문/CTA를 구조화 분석하여 AI 리라이팅의 기초 데이터를 제공합니다.

### 🌟 주요 기능
- **유튜브 원본 대조**: 분석 중 원본 영상 링크로 이동하여 연출 및 자막 싱크 대조.
- **구간별 후킹 분석**: 시청 지속 시간을 극대화하는 3초 후킹 멘트와 핵심 키워드 자동 태깅.
- **AI 대본 각색실 연동**: 추출된 대본을 `AI 대본 각색실(/script-writer)`로 원클릭 전달.

## 4. 쇼츠 자동 배포 관리 (`/work-queue`)

유튜브 쇼츠, 틱톡, 인스타그램 릴스에 콘텐츠를 예약/즉시 자동 업로드하고 진행 상태를 통합 관제하는 오케스트레이션 센터입니다.

### 🌟 주요 기능 및 최신 개선 사항
1. **🔍 실시간 다차원 통합 검색 & `X` 즉시 지우기**:
   - 제목, 채널명, 설명, 파일명, ID, 프로젝트 그룹명을 입력 즉시 클라이언트 사이드에서 실시간 필터링합니다.
   - 검색어 입력 시 우측에 나타나는 `X` 버튼으로 원클릭 초기화가 가능합니다.
2. **🔀 다기능 정렬 컨트롤 (`Sort & Toggle`)**:
   - **정렬 기준**: `📅 등록순` (등록일시), `⏰ 예약순` (발행 예약일시), `📺 채널순` (채널명 가나다순), `🏷️ 상태순` (대기열/완료/실패 등)
   - **정렬 방향 토글 (`ArrowUpDown`)**: 클릭 한 번으로 최신순 ↔ 과거순, 오름차순 ↔ 내림차순 즉시 전환.
3. **🎯 정밀 다채널 & 업로드 방식 세부 필터**:
   - **채널 필터**: 등록된 유튜브, 틱톡, 인스타그램 채널 중 특정 채널의 쇼츠만 선별.
   - **업로드 방식 필터**: `🤖 스텔스 자동`, `✍️ 수동 업로드`, `⚡ 즉시 등록` 구분 필터.
   - **프로젝트 그룹 & 기간 필터**: 픽셀링 배치 ID별 또는 기간(오늘/7일/30일/전체)별 보기.
4. **📱 모바일 & PC 반응형 레이아웃 완벽 최적화**:
   - 드롭다운 내부 글자가 두 줄로 깨지거나 잘리는 현상을 완벽 방지(`whitespace-nowrap`).
   - 모바일 환경에서는 1행 검색창 + 2행 가로 스크롤 칩 바로 구성되어 한 손 조작이 쾌적합니다.

## 5. 채널 계정 & 웜업 육성 (`/incubator` & `/vault`)

스텔스 안티디텍트 브라우저 환경에서 구글/소셜 채널을 안전하게 관리하고, 신규 계정을 7단계 인간 행동 모사 알고리즘으로 안전하게 육성합니다.

### 🌟 주요 기능 및 최신 개선 사항
1. **📊 일괄 웜업 육성 제어 KPI 카드 리디자인**:
   - `전체 채널`, `진행 중`, `완료됨`, `오류 발생`, `일시정지`, `대기 중` 6개 상태 카드를 깔끔하고 직관적인 미니멀 스타일로 통일.
2. **📱 모바일 계정 목록 카드 전면 개편**:
   - **이메일 영역 확장**: 상단 1열 전체를 이메일 전용으로 확보하여 긴 계정 주소도 잘림 없이 선명하게 표시.
   - **인코딩 깨짐 완전 정제**: 비정상 유니코드나 물음표 접두사(`뚊??go-global` 등)를 자동 정제하여 실제 채널명(`go-global`)만 정갈하게 표시.
   - **`layout="stacked"` 웜업 컨트롤**: 좁은 모바일 화면에서도 웜업 상태 뱃지와 UI 표시 스위치가 상단에 여유롭게 배치되고, 하단에 `[🔥 웜업 시작]`과 `[⚙️ 전략 설정]` 버튼이 균형 잡힌 2단 그리드로 배치되어 텍스트 찌그러짐이 0%입니다.
   - **미니멀 `API 🟢/🟡` 뱃지**: 인증 상태를 직관적인 원형 인라인 뱃지로 간결하게 표시.

## 6. 다중창 통합 관리 및 반응형 환경 지원

- **환경 자동 감지 (`isElectron`)**:
  - Electron 데스크톱 앱에서만 다중 창 관리 툴바가 활성화되며, 모바일이나 일반 크롬 브라우저 접속 시에는 화면을 가리지 않도록 불필요한 컨트롤이 자동으로 숨겨집니다.
- **원격 워크스테이션 브리지**:
  - 스마트폰에서 작업한 프로젝트 데이터도 메인 PC의 CapCut 로컬 경로로 안전하게 전송 및 조립됩니다.

## 7. 자주 묻는 질문 (FAQ) & 팁

**Q. 모바일 브라우저에서 '폴더 열기'를 눌렀을 때 어떻게 동작하나요?**  
> 모바일이나 원격 크롬에서는 PC 로컬 파일 시스템을 직접 열 수 없으므로, 해당 영상이 저장된 표준 경로가 스마트폰 클립보드에 자동으로 복사됩니다.

**Q. 웜업 진행 시 'UI 표시' 스위치는 언제 사용하나요?**  
> 웜업 봇이 유튜브에서 영상을 탐색하고 시청하는 과정을 실시간 눈으로 확인하고 싶을 때 `UI 표시`를 켜면 스텔스 브라우저 창이 화면에 표시됩니다. 백그라운드 무인 실행을 원하시면 꺼두시면 됩니다.

**Q. 대기열 검색 시 특정 채널의 영상만 찾으려면 어떻게 하나요?**  
> 검색창에 채널명을 직접 타이핑하시거나, 검색창 우측의 **`[전체 채널]` 드롭다운**에서 원하는 채널을 선택하시면 즉시 필터링됩니다.
