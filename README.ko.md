## ⚡ v0.9.33 Baseline: 초경량 스마트 핫패처(OTA) 탑재

`v0.9.33`부터 **차세대 스마트 핫패처(Over-The-Air Hot-Patch) 엔진**이 공식 탑재되었습니다.

```
[📦 최초 설치 (1회)] ───► ViraLoop.Studio-0.9.33-win-x64-Setup.exe (단일 설치 파일)
                                │
[🔄 이후 업데이트]   ───► 앱 실행 시 GitHub에서 2MB 초경량 패치 (update-bundle.zip) 1초 만에 자동 동기화!
                                │
[🛡️ 데이터 안전성]   ───► 재설치/업데이트 시에도 구글 로그인 세션, 채널 설정, DB 100% 영구 보존!
```

* **대용량 재설치 Zero**: 기능 개선 및 버그 수정 시 700MB 설치 파일을 매번 다시 받을 필요 없이, **앱 실행 시 1~2초 만에 백그라운드로 자동 패치**됩니다.
* **데이터 완전 보존**: Google Flow 다중 세션(`Partitions`), 채널 목록 및 DB(`viral_loop.db`), 다운로드 미디어(`07_Downloads`)는 앱 바이너리와 분리된 전용 영구 저장소(`AppData\Local\ViraLoop Studio`)에 안전하게 보존됩니다.

## 🚀 30초 원클릭 설치 가이드

사전 설치 프로그램(Git, Node.js, Python, FFmpeg 등)이 전혀 없는 윈도우 PC에서도 즉시 설치할 수 있습니다.

### 방법 1. 정식 Windows 인스톨러 (추천 ⭐)
1. [GitHub 최신 릴리즈](https://github.com/jmyoon312/VLStudio/releases/latest)에서 **`ViraLoop.Studio-0.9.33-win-x64-Setup.exe`** 다운로드
2. 실행하여 설치 완료 후 바탕화면 **"ViraLoop Studio"** 아이콘으로 실행

### 방법 2. PowerShell 명령어 1줄 실행 (가장 빠름 ⚡)
**시작 버튼 우클릭 → [터미널] 또는 [PowerShell]**을 열고 아래 명령어를 붙여넣은 뒤 엔터를 누르면 무인 자동 설치됩니다:
```powershell
irm https://raw.githubusercontent.com/jmyoon312/VLStudio/main/install.ps1 | iex
```

### 1. 📡 바이럴 스카우터 2.0 (FSD 자율 탐색 & 채널 성장 분석 엔진)
* **4단계 비즈니스 파이프라인 퍼널 완비**:
  1. **STEP 1 (바이럴 시그널 발굴)**: `yt-dlp` 실시간 유튜브 트렌드 검색을 통해 실제 바이럴 배수(Outlier Ratio), 시간당 조회수 속도, 3초 훅 분석 자동 추출.
  2. **STEP 2 (벤치마크 채널 릴 & 성장 해체)**: 픽셀링식 수평 채널 스트립 뷰. 채널 클릭 시 **채널 성장 분석 모달(`ChannelAnatomyModal`)**이 오픈되어 **누적 성장선(라인)**과 **일간 속도(막대)** 듀얼 차트, 성장 가속도(`현재 속도: 1.4만 / 가속 · 137%`), 9router LLM 기반 **바이럴루프 특화 4대 AI 해체 리포트**(후킹 심리 기제, 떡상 요인, 10x 리메이크 각색안, Google Flow AI 프롬프트) 실시간 생성.
  3. **STEP 3 (픽셀링 시드 카테고리 인큐베이터)**: 전문가 엄선 20대 카테고리(`한국인물티셋`, `심리학`, `원테이크크루`, `시니어(건강)` 등)와 카테고리 DNA 헌장 설정.
  4. **STEP 4 (신설 채널 론치패드)**: 카테고리 기반 5대 브랜드 기획안(채널명 3종, 아바타/배너 프롬프트, 초기 3편 훅 플랜) 자동 패키징 및 브랜드 채널 자동 등록.
* **타겟 채널 중복 배제 (Deduplication Rule)**: 이미 정기 자동 수집(`/channels`)에 등록된 채널(`auto_download == True`)은 탐색 릴에서 완전 제외하여, 크리에이터가 오직 **"새롭게 발굴된 미등록 옥석"**에만 집중할 수 있도록 보장.
* **인간 검토 승인 게이트**: 채널 릴 및 모달에서 `[✓ 타겟 채널 승인 & 정기수집 전환]` 원클릭으로 정기 수집 채널로 승격 이동.

### 2. 🎬 Creative Studio (AI 미디어 일괄 생성)
* **Google Flow & Veo 3.1 네이티브 연동**: 브라우저 확장 없이 데스크톱 앱 내에서 직접 Google Flow 세션을 제어하여 고화질 영상 및 이미지 일괄 생성.
* **CapCut 초고속 다이렉트 내보내기**: 생성된 비디오 클립과 오디오를 압축 해제 과정 없이 로컬 CapCut 프로젝트 폴더에 0.1초 만에 즉시 조립.

### 3. ⚡ Ddalkkak Studio (딸깍 숏폼 자동 제작 시스템)
* **글로벌 숏폼 소싱 & 디섹션(분해 분석)**: 유튜브/더우인 인기 쇼츠를 소싱하여 대본 추출 및 트렌드 바이럴 포인트 자동 분석.
* **원어민 윤문 & 인물별 멀티 TTS**: 어색한 직역을 배제하고 현지 원어민 뉘앙스로 재작성 후, 캐릭터별 목소리를 매핑하여 고품질 음성 자동 합성.

### 4. 🎙️ Subtitle & Dubbing Studio (자막 및 더빙 스튜디오)
* **5중 음성 분석 엔진**: 고정밀 타임코드 기반 SRT 자막 자동 생성 및 오디오 싱크 정렬.
* **무음 자동 제거 (Silence Remover)**: 불필요한 공백 구간을 스마트 감지하여 템포가 빠른 숏폼 영상으로 자동 커팅.

### 5. 📋 WorkQueue & Pixeling (작업 대기열 & 메타 매칭)
* **픽셀링 메타 OCR 자동 매칭**: 추천 메타 텍스트와 쇼츠 영상을 시각적 OCR로 자동 매칭하여 예약 대기열에 일괄 등록.
* **다채널 무인 예약 배포**: 유튜브, 틱톡, 인스타그램 채널별 스케줄에 맞춰 자동 업로드 실행.

### 6. 🤖 Hermes AI & Strategic CoPilot
* **내부 설정 단일 진실 공급원 (SSOT)**: 시스템 환경 설정(DB Settings)에 지정된 LLM 모델을 실시간 동적 연동하여 대본 분석 및 프롬프트 생성.

### 7. 📱 Mobile LTE Clean IP Incubator
* **스마트폰 USB 테더링 클린 IP**: 안드로이드 폰을 연결하여 통신사 순수 LTE/5G IP를 데스크톱으로 직결.
* **자동 비행기 모드 IP 순환**: 계정 생성 및 업로드 시 IP를 자동 교체하여 플랫폼 섀도우밴 원천 차단.

### 8. 📺 Virtual Live Studio (24/7 무인 라이브)
* **무중단 다채널 동시 송출**: 로컬 미디어 라이브러리를 기반으로 유튜브, 틱톡 등에 24시간 실시간 무인 스트리밍 송출.

## 📱 원격 워크스테이션 & 스마트폰 모바일 워크플로우

ViraLoop Studio는 호스트 메인 PC뿐만 아니라, **스마트폰(모바일 브라우저)이나 외부 노트북 크롬에서도 메인 PC의 고성능 엔진을 원격 제어**할 수 있는 원격 워크스테이션 아키텍처를 지원합니다.

* **로컬 웹 대시보드**: `http://localhost:5183`
* **사내/홈 LAN 접속**: `http://192.168.x.x:5183` (스마트폰에서 대용량 영상 즉시 업로드 & 원격 제어)
* **공인 터널/도메인 연동**: `https://viraloop.gogloo.gleeze.com` 등을 통한 외부 원격 관제 지원
